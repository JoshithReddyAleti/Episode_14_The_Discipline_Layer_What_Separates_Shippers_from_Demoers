# Contributing to Episode 14

Thanks for your interest in improving this episode. This is part of the AI Engineering Roadmap 2026 series.

## Ways to contribute

- **Fix an error.** Typos, factual mistakes, broken links — all welcome via PR.
- **Deepen a section.** Add references, better examples, more numeric grounding.
- **Add a discipline example.** New runnable lab illustrating a pattern.
- **Improve utilities.** Extend stats_utils, security_utils, or prompt_utils.

## Ground rules

- **Substance over decoration.** Every change should teach or test something.
- **Real numbers.** Include realistic performance / cost / accuracy figures where relevant.
- **Cite sources.** Papers, blog posts, official docs.
- **Direct voice.** This series is written for practitioners; avoid marketing tone.
- **No copyrighted content.** Content should be original or under compatible license.

## PR process

1. Fork and branch.
2. Small, focused changes.
3. Include tests for utility changes.
4. Run `make lint` and `make test`.
5. Open PR with clear description.
