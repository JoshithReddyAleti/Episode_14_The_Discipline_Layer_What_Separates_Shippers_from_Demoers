# Glossary — Episode 14

**ANN** — Approximate Nearest Neighbor.

**ASR** — Attack Success Rate.

**BM25** — Best Matching 25 (keyword ranking function).

**CDC** — Change Data Capture.

**CFG** — Context-Free Grammar.

**CI** — Confidence Interval (statistics) or Continuous Integration (deployment).

**CoT** — Chain of Thought.

**CoVe** — Chain of Verification.

**CUPED** — Controlled Using Pre-Experiment Data (variance reduction).

**DFA** — Deterministic Finite Automaton.

**DiD** — Difference-in-Differences (causal inference).

**DPA** — Data Processing Agreement.

**DSL** — Domain-Specific Language.

**DSPy** — Declarative Self-improving Python (framework).

**DVC** — Data Version Control.

**EBNF** — Extended Backus-Naur Form (grammar notation).

**FDR** — False Discovery Rate.

**FF** — Feature Flag.

**FSA** — Finite State Automaton.

**GBNF** — Grammar in Backus-Naur Form (llama.cpp).

**GCG** — Greedy Coordinate Gradient (jailbreak).

**GoT** — Graph of Thoughts.

**HNSW** — Hierarchical Navigable Small World (ANN algorithm).

**HTE** — Heterogeneous Treatment Effect.

**IPW** — Inverse Probability Weighting.

**IV** — Instrumental Variable.

**IVF** — Inverted File Index.

**LLM-as-judge** — Using an LLM to evaluate other LLM outputs.

**LSH** — Locality-Sensitive Hashing.

**MDE** — Minimum Detectable Effect.

**MinHash** — Hash-based Jaccard similarity estimator.

**OWASP LLM Top 10** — Standard vulnerabilities for LLM apps.

**PAIR** — Prompt Automatic Iterative Refinement (automated jailbreak).

**PDA** — Pushdown Automaton.

**PoT** — Program of Thoughts.

**PQ** — Product Quantization.

**RAG** — Retrieval-Augmented Generation.

**RDD** — Regression Discontinuity Design.

**RLAIF** — RL from AI Feedback.

**RLHF** — RL from Human Feedback.

**SDL** — Secure Development Lifecycle.

**SIEM** — Security Information and Event Management.

**SOC 2** — Service Organization Control 2 (security standard).

**SoT** — Skeleton of Thought.

**SQ** — Scalar Quantization.

**SRM** — Sample Ratio Mismatch.

**SUTVA** — Stable Unit Treatment Value Assumption.

**TAP** — Tree of Attacks with Pruning (jailbreak).

**ToT** — Tree of Thoughts.

**WAF** — Web Application Firewall.
